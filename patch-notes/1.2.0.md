The 1.6.0-era refit: the whole catalog moves onto CommonLib's shared economy, the broker NPCs work again, and the pack now asks for MMO Skill Tree 1.6.0, the CommonLib 2.0.0 jar, and a Hytale Update 6 server. For anyone coming from 1.1.2, the held 1.1.3 changes (the multi-wallet page headers, the deliberate Token Shop category order, and the Fisher's Haul price fix) ship in this same update.

- **Requires MMO Skill Tree 1.6.0 and CommonLib 2.0.0, on an Update 6 (0.6.x) server.** The pack does not load against older versions of either; update the mod, the library jar and the server together, then drop this pack in with them.
- **New: the catalog speaks the shared economy.** Every contract, board, storefront, shelf, offer and wallet is authored in CommonLib's shared commerce format, and all 85 contracts pay through the shared reward system, still claimed at the board you took them from. Contract ids keep their spelling, so saved progress, achievement criteria and dialogue references all survive the update.
- **New: the achievements ride the shared progression format.** The eleven board and creature achievement ladders move onto the shared store with their chains intact; ids and criteria order hold steady, so nobody loses progress.
- **Fixed: the six broker NPCs load again.** Every broker role in the pack failed at server start (each pressing-use action named a screen opener that no longer exists), printing six errors per boot. Pressing use on a broker now opens whatever the placement that stood it up says, so one role can serve any number of brokers aimed at different boards or storefronts. The pack deliberately ships no placements - where a broker belongs is your server's call - and each role file carries a ready-to-paste placement recipe with its id and destination already filled in.
- **Update 6: the boards and the trader drop the retired usable flag.** Pressing use on a placed board or trader block is driven by the block's own use interaction on 0.6, so the old flag is gone from every block in the pack.
- **The Bounty Token names itself in all nine languages.** The token's balance chip reads translated everywhere it appears.
