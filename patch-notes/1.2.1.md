Two boss-fight contracts on the game's encounter scripts, a higher library floor, and two small fixes: the hub screen's wording, and the broker NPCs' environmental immunity.

- **Requires ZiggfreedCommon 2.1.0, beside MMO Skill Tree 1.6.1.** The boss contracts count a kind of moment the 2.1.0 library is the first to fire, and that library ships with 1.6.1; update the mod, the library jar and this pack together.
- **New: an Open Warrant on the Weekly board.** A Hard contract with no name on it: bring down any boss the game's encounter scripts run, whichever one your server stands up, and it is settled for everyone the fight credited, whoever landed the last blow. It pays Bounty Tokens and Defense experience, sized above the single-creature weekly hunts.
- **New: The Muster Roll on the Daily board.** A Normal contract for standing in a boss fight until it is settled, win or lose. Being counted at the fight is the whole ask, so a party that wipes is still paid for showing up.
- **New: a `Bounty_Encounter` skeleton for boss contracts of your own.** Name an encounter script id to tie a contract to one fight, or leave the target out for any boss, and swap its kind to count fights fought to the end instead of kills. The pack's authoring guide carries the worked example. On a server where no boss stands anywhere, take the two shipped contracts off the boards with `"Enabled": false`.
- **Fixed: the six broker NPCs shrug off environmental damage, as they were always meant to.** Every broker role asked for the Immunity_Environmental effect under a key the engine does not read (`EntityEffect`), so the request was silently ignored and the server logged an unused-key warning for each role at boot. The roles now author `EntityEffects` as the list the engine expects, the same spelling the base game's own passive NPCs use.
- **Fixed: the hub screen keeps the guide's own name.** This pack shipped its own text for the hub title and the Token Shop hint (Bounty Master & Trader, "Spend your hard-earned tokens."), the same two lines the plugin defines for the Adventurer's Guide, so the server warned about a doubly defined key in every language at boot and which wording won depended on load order. The two lines leave the pack; the plugin's wording shows, and every other hub line this pack ships stays where it is.
