A one-line fix for the hub screen's wording.

- **Fixed: the hub screen keeps the guide's own name.** This pack shipped its own text for the hub title and the Token Shop hint (Bounty Master & Trader, "Spend your hard-earned tokens."), the same two lines the plugin defines for the Adventurer's Guide, so the server warned about a doubly defined key in every language at boot and which wording won depended on load order. The two lines leave the pack; the plugin's wording shows, and every other hub line this pack ships stays where it is.
