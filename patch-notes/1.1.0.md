Two new boards for quick, XP-focused jobs, alongside the existing Daily and Weekly contracts. Requires MMO Skill Tree 1.4.0.

- **New: Daily Contracts board.** A board whose whole slate is active at once and refreshes each day, carrying the everyday gather, hunt, fish, and deliver jobs that used to live inside the mod itself. These pay mostly in skill XP with only a token nod, so the Daily and Weekly boards stay your main source of Bounty Tokens.
- **New: Quick Contracts board.** A single short contract that rotates several times a day - a fast bit of gathering, fishing, building, or culling for a burst of skill XP between the bigger hunts. Reroll it for a few tokens if it is not your thing.
- **New objective flavors.** With the 1.4.0 engine the pack can now post place-blocks, catch-fish, harvest, and "spend at the shop" contracts, including a Market Patron contract that rewards trading at the exchange.
- **Requires MMO Skill Tree 1.4.0.** The new boards use engine features added in 1.4.0, so update the mod alongside this pack.
